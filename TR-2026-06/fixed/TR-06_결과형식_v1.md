# TR-2026-06 결과 파일 형식 v1

- 근거: 사전 등록 v0.2 §6 · §7 · §9 · §10. 2026-10-02 작성 — **결과를 보기 전에 고정한다.** 실행기(`native/tools/robot_program_tr06.cpp`, 맥에서 작성)는 이 형식으로 쓴다. 독립 검산(`TR-06_독립검산.py`)과 공개본 변환(`TR-06_공개본변환.py`)은 이 형식만 믿는다.
- 형식을 바꿔야 하면 v2 문서를 새로 만들고, 두 스크립트를 결과 전에 함께 고쳐 해시를 다시 적는다.

## 실행 폴더

| 파일 | 내용 |
| --- | --- |
| `run.json` | 실행 정보 |
| `labels.json` | 형태 라벨 — **계획을 돌리기 전에** 쓴다 |
| `results.jsonl` | 한 줄 = (모델 · k · 해법 · 속도 · 계획 회차) 하나 |
| `e1.jsonl` | 한 줄 = (모델 · 관절 · m) 하나 |
| `summary.json` | 실행기가 센 §7 분자/분모와 판정 — 독립 검산이 대조한다 |
| `precheck.json` | 사전 대조 결과(§9) |

여섯 파일 모두 필수다. 하나라도 없으면 독립 검산이 [FAIL] 로 끝낸다.

## run.json

```
{"schema": "tr06-run/v1", "run_id": "...", "product_commit": "<40자>", "runner_commit": "<40자>",
 "inputs_sha256": "<입력목록_v2.json>", "labels_sha256": "<labels.json>", "compiler": "...",
 "started_utc": "...", "finished_utc": "...",
 "labels_written_utc": "...", "first_plan_utc": "...",
 "limits_ok_inputs": true, "limits_ok_e1": true}
```
- 시각은 ISO 8601(시간대 포함). `labels_written_utc` 는 `first_plan_utc` 보다 앞이어야 한다.
- `product_commit` 은 `e2dc7a7846a59952fb6c76d63b89137bef5129ab`, `inputs_sha256` 은 `TR-06_입력목록_v2.json` 의 값이어야 한다(독립 검산에 고정값으로 들어 있다).
- `limits_ok_inputs` = 720건 양 끝이 모델별 관절 한계 안, `limits_ok_e1` = E1 2,880건이 방향 규칙에서 한계 안. 거짓이면 실행 무효.

## labels.json

```
{"schema": "tr06-labels/v1", "method": "<판정식 설명>", "wrist_band_deg": <손목 판정 경계 폭>,
 "labels": [{"model": "<모델>", "k": 0, "start": L, "target": L}, ...]}
```
L = `{"wrist": "+"|"-"|"?", "elbow": "+"|"-"|"?", "shoulder": "+"|"-"|"?", "turn4": 정수, "turn6": 정수}`. `"?"` = 판정 불가(경계 안).

## results.jsonl

| 키 | 형 | 뜻 |
| --- | --- | --- |
| `model` | 문자열 | 원본은 내부 표시, 공개본은 A~L |
| `k` | 정수 | 입력 번호 |
| `solver` | `C0` `C1` `C2` `C3` `C2z` | 해법(§6-1) |
| `speed` | `base` `half` | 기본 속도 / 50% 속도(C0 만) |
| `plan_round` | 1 · 2 | C0 · base 만 2회, 나머지는 1 |
| `start_deg` · `target_deg` | 6실수 | 입력 그대로 |
| `end_deg` | 6실수 | 끝 표본 관절 값(미수렴이면 마지막으로 저장된 해). 공개본 B~L 에는 없다 |
| `end_over_001` | 6불 | 관절별 \|끝 − 목표\| > 0.01 |
| `end_label` | L | 끝 관절 값의 형태 라벨 |
| `converged` | 불 | 계획 수렴 |
| `samples` · `ik_fail_samples` | 정수 | 표본 수 · 풀이 실패 표본 수 |
| `ik_fail_causes` | `{"unreachable","limit","budget"}` 정수 | 풀이 실패 원인 3분류 |
| `end_pos_err_mm` · `end_rot_err_deg` | 실수 | 끝 공구 끝 위치 · 방향 차이 |
| `end_iters` | 정수 | 끝 표본에서 쓴 반복 수 |
| `max_step_deg` | 실수 | 이웃 표본 사이 가장 큰 관절 변화. 공개본 B~L 에는 없다 |
| `max_step_joint` · `max_step_index` · `max_step_s` | 정수 · 정수 · 실수 | 그 관절 · 표본 번호 · 진행률 |
| `j4_travel_deg` · `j6_travel_deg` | 실수 | 누적 회전량 |
| `min_manipulability` | 실수 | 경로 위 최소 조작성. 공개본 B~L 은 모델별 최댓값으로 나눈 비 |
| `max_speed_ratio` | 실수 | 가장 큰 관절 속도 비율. 공개본 B~L 은 소수 둘째 자리 |
| `findings` | `{종류: {"warn": n, "block": n}}` | 제품 점검기 소견. 종류 이름은 고정: `end_joint_mismatch` · `ik_fail` · `joint_speed` · `joint_accel` · `manipulability` · `line_deviation` · 그 밖은 `other_<이름>` |
| `verdict` | `{"V","T","V_cfg"}` 각 `allow`/`block` | 실행기 판정 |
| `mismatch` · `type` | 불 · `a`~`e` `x` 또는 null | 실행기 판정 |
| `plan_hash` | 문자열 | 계획 해시 |

판정 규칙(독립 검산이 다시 유도하는 식 — 실행기도 같게 판정한다):
- V = `findings` 의 block 합이 0 이고 풀이 실패 표본이 0 이고 `converged` 이면 allow(풀이 실패 · 미수렴은 제품 등급과 상관없이 차단, 사전 등록 §3).
- T = `end_joint_mismatch` 를 뺀 block 합이 0 이고 풀이 실패 표본이 0 이고 `converged` 이고 `end_pos_err_mm ≤ 0.01` 이고 `end_rot_err_deg ≤ 0.01` 이면 allow.
- V_cfg = 시작 · 목표 라벨(손목 · 팔꿈치 · 어깨 · turn4 · turn6)이 모두 같고 `"?"` 가 없으면 T 와 같게, 아니면 block.
- mismatch = `end_over_001` 에 참이 하나라도 있음.
- type: §6-3 과 같고 우선순위 (e) → (x) → (c) → (b) → (a) → (d). (x) = 끝 또는 목표 라벨에 `"?"`.

독립 검산이 대조하는 앞뒤 조건(어긋나면 [FAIL]):
- `mismatch` ⇔ `findings.end_joint_mismatch.block > 0`.
- `max_speed_ratio > 1 × (1 + 1e-9)` ⇔ `findings.joint_speed.block > 0`.
- `ik_fail_samples > 0` ⇔ `findings.ik_fail` 의 warn + block > 0, 그리고 `ik_fail_causes` 합 = `ik_fail_samples`.
- 소견 종류 이름은 위 고정 목록이나 `other_` 로 시작하는 이름만.
- 실수 값은 모두 유한(NaN · 무한 금지).
- 행 조합은 (해법, base, 1) 다섯 가지 + (C0, base, 2) + (C0, half, 1) 만, 모델 12개 × k 60개 × 7 = 5,040행.
- C0 1 · 2회차 행은 `plan_round` 만 다르고 나머지가 모두 같아야 한다.
- C1 · C3 행은 끝 불일치가 없고 `end_label` 이 목표 라벨과 같아야 한다.

## e1.jsonl

`{"model", "joint": 1~6, "m": 1~40, "max_speed_ratio", "block_strict": 불, "block_margin": 불, "start_deg", "distance_deg", "duration_s", "accel_deg_s2"}` — 이 키만 쓴다. `block_strict` = 비율 > 1, `block_margin` = 비율 > 1 × (1 + 1e-9). 12 × 6 × 40 = 2,880줄, (모델, 관절, m) 중복 없음. 공개본 B~L 은 `model · joint · m · block_strict · block_margin` 만.

## precheck.json

`{"negative": {"expect": "none", "got": …}, "positive_turn": {"expect": "a", "got": …}, "positive_wrist": {"expect": "b", "got": …}, "c0_bit_identical": 불, "inputs": {…사전 대조 입력…}}` — `got` 은 그 직선의 유형(불일치 없으면 `none`). 셋 다 `expect` 와 같고 `c0_bit_identical` 이 참이어야 한다.

## summary.json

`{"schema": "tr06-summary/v1", "predictions": {…}}` — `predictions` 는 `TR-06_독립검산.py` 의 `predictions` 출력과 **키 · 값이 모두 같아야** 한다(P1 · P2 · P3 · P5 · P6 · P7a · P7b 는 `{x, n, verdict}`, P7 은 `{verdict, excluded_x}`, F1 은 `{x_cross, n_cross, x_noncross, n_noncross, verdict}`, F2 는 `{x, n, verdict}`, F3 은 `{by_solver: {C1, C2, C3: {x, n, verdict}}, verdict}`). verdict 낱말: P = 맞음 · 틀림 · 판정 불가, F = 성립 · 불성립 · 판정 불가.

## 공개본(B~L) 행

`TR-06_공개본변환.py` 가 만든다. results 는 허용 키만 남기고 `end_deg` · `max_step_deg` · `samples` · `max_step_index` · `ik_fail_samples` · `ik_fail_causes` 를 빼며, 대신 `ik_fail_any`(불) · `ik_fail_cause_any`(원인별 불)를 넣는다. 속도 비는 소수 둘째, 최소 조작성은 모델별 최댓값으로 나눈 비. 행은 (모델, k, 해법, 속도, 회차) 순으로 정렬한다. run.json 에 `original_sha256` 을 넣고 `labels_sha256` 은 뺀다.
