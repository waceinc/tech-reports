## Path redaction

No other byte changes. `scripts/redact_paths.py` does the replacement, refuses input that already contains the placeholder, and checks for every file that restoring the prefix gives back the original bytes. Two runs of the packing produced the same archive. The prefix is not released, so the original hashes of the five path-redacted files and of the 1,632 changed archive members cannot be reproduced from this bundle alone. ## Reproducing the checks

```
tar -xJf runs/tr02-official-1.tar.xz                      # -> tr02-official-1/
python3 scripts/TR-02_리드독립검산.py tr02-official-1/       # P1-P4 and the 5.8 split
python3 scripts/recompute_metrics_1_2.py . tr02-official-1/        # metric 1 verdicts and metric 2
python3 scripts/reextract_numbers.py . tr02-official-1/ <report.md>
python3 scripts/make_figures.py . tr02-official-1/ out/                 # SVG + PNG (PNG if rsvg-convert is installed)
```

Figures: `make_figures.py` reads only bundle files (result file, extracted run archive, figures/wace-wordmark-white.svg), writes SVG with the badge drawn in and renders PNG with `rsvg-convert -w 1600` (librsvg 2.63.2 here). Two runs on the author's machine gave byte-identical SVG, PNG and figure_values.json. The SVG files are byte-reproducible from the bundle; PNG pixels depend on the renderer and installed fonts (a sandboxed run without access to the badge font gave identical SVG and different PNG). Badge (Korean): "시뮬레이션 · 실물 대조 0" (simulation · 0 physical comparisons) and "© WACE · CC BY 4.0". The notice "no reuse without permission" is used only on screen captures and videos of the company's 3D viewer (internal program name Vision 2), none of which is in this bundle. Figure 1 shows the per-scan forward output instead of the ladder's confirmation bit named in the pre-registration, because the confirmation bit is not recorded in the traces.

## Isolated recomputation

A copy of this bundle (without this MANIFEST and the output record) and the extracted archive were placed in an empty folder. `recompute_metrics_1_2.py` was run there under the macOS sandbox with read access denied to every user directory, mounted volume and temporary folder except that folder (a control read of the private repository under the same sandbox failed with "Operation not permitted"). Result: 816 of 816 run verdicts equal to summary and ledger, metric 1 equal to the result file, metric 2 8 of 8 entries equal. With one summary status and one metric-2 value altered in the copy, the same run reported both differences and exited non-zero.

Not released: the PLC simulator engine and engine host, the plant-model program (with the cell file and reference logic), the other runner files and tag maps, the run-version ladders and the redaction map with the original prefix. No run can be re-executed from this bundle.
