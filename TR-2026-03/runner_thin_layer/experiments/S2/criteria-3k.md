## F1 — 3k 래더·태그표·참조 일치·시드 분류·결정성

1. 태그표: `cells/cell-b.tagmap.*`·`cells/cell-b-pack.tagmap.*` 를 phase3k io-map 에서 생성. 3j 태그 주소·형식 변경 0, 새 태그 = 분류 태그표 8점(Y3A + D640~D646 워드 7), 포장 태그표 10점(여기에 D647·D648). 워드 형식 INT, 방향 out.
2. 래더 정적: 정답 3·음성 전부 컴파일, 임시 이름 0, 내부 태그 주석 누락 0, BOOL 이중 코일 0. 새 워드·Y3A 는 출력 묶음에서 한 번씩 결정한다.
3. 정상: A 1000틱 3왕복, B 5000틱 시드 1/2/3 각 20개, 포장 10000틱 시드 1/2/3 각 60개 — ID별 판정·경로가 공급 분류표와 일치, 정상 위험 사건 0, 참조 일치.
4. 결정성: 위 7개 실행을 독립 2회, 모든 틱 해시 동일.
5. 워드 값: 모든 정답 실행의 매 스캔 워드가 io-map 값 표(열거 워드) 또는 0 이상 정수(코드·수) 안.
6. 복귀: recovery(마무리 밀기)·recovery-retract 3420틱 참조 일치, 물리 위험 사건 0. D641 값이 바뀐 순서가 3k 보고 실측 순서와 같다 — 마무리 경로 `0,1,2,3,4,5,6,7,8,0`, 후진 경로 `0,1,2,4,5,6,7,8,0`. 재검 수(D643)는 격리 뒤 1 이상이고 추적 초기화 뒤에도 유지, 양품·불량 수에 재검 상자를 넣지 않는다(참조 일치로 판정).
7. 기존 시나리오 회귀: curtain·cycle-stop·batch·flow70/50(정답·no-sort-check 1000틱) 은 3j 기준(criteria-3j.md)의 판정식 그대로, 정답은 참조 일치 추가.
8. 음성: 3j 음성 7종(연결 실행)이 3j 와 같은 사건으로 [FAIL] 검출. 자체 시험의 3j 음성 3종도 그대로.
9. 포장 고장: 포장 셀 6000틱 — 2000틱 로봇1 구동 고장(60틱 뒤 해소), 2120~2124 리셋, 4000틱 케이스 교환기2 고장(같은 방식) — 참조 일치, D647 에 1·4, D648 에 105·135 가 나오고 리셋 해제 뒤 0.

## F2 — 32비트 감김·행정 경고

1. 방식: 누적 위치(UDINT, 1 펄스 = 1 mm)와 누적 스캔(DINT)은 모두 (현재 − 기준) 차분으로만 비교한다. 빈 칸은 유효 비트로 표시한다(값 0 을 빈 칸 뜻으로 쓰지 않는다).
2. 넘침 시작 시나리오(B 시드 1, 5000틱): 래더 계수 시작값을 엔진 메모리에 쓰고, 정답도 같은 시작값(`count_start_position`·`count_start_scan`)으로 만든다. 시작값은 계수 0 시작 정답 실행(시드 1)의 기록에서만 계산한다:
   - P1 위치 UDINT 감김: 위치 시작 = 2^32 − 30000
   - P2 위치 UDINT 감김이 첫 불량의 밀기 발사 창 안(등록 뒤 100 펄스): 위치 시작 = 2^32 − (등록 위치 + 100)
   - P3 위치 부호 경계(정답 DINT 감김) 발사 창 안: 위치 시작 = 2^31 − (등록 위치 + 100)
   - S1 스캔 DINT 감김: 스캔 시작 = 2^31 − 2500
   - S2 스캔 감김이 첫 불량 도착 뒤 10 스캔(슈트 확인 대기 중): 스캔 시작 = 2^31 − (도착 틱 + 10)
   - PS 위치·스캔 동시: P2 와 S2 를 함께
   각 [PASS] = 20개 분류·경로가 계수 0 시작과 같음, 위험 사건 0, 잠김 없음, 참조 일치, 매 틱 Q(워드 포함)가 계수 0 시작 실행과 같음.
3. 음성 `abs-compare`(3j 방식 절대 비교·값 0 빈 칸 표지): P1·P2·P3 중 1건 이상, 그리고 P2 에서 [FAIL](분류·사건·잠김·계수 0 시작 대비 Q 중 하나라도 다름). 스캔 넘침(S1·S2)에서 검출 여부는 기록만 한다.
4. 행정 경고: stroke75(유량 0.75, 2600틱) 에서 D646 이 1 이상이 되고 그동안 Y3A 가 0.5 s 간격으로 켜짐. strokeclear(6000틱: 유량 0.75 → 경고 → 잠김 → 화면 워드만 보고 복귀 → 추적 초기화 뒤 유량 1.0 → 재기동) 에서 D646 이 1 이상이 된 뒤 0 으로 돌아오고, 경고 전·해제 뒤 Y3A 는 0. 두 실행 모두 참조 일치. 음성 `warn-latch`(해제 없음)는 strokeclear 끝에서 D646 이 0 이 아니어서 [FAIL] 검출.
5. 자체 시험(실제 엔진): 누적 위치 넘침 직전 시작에서 발사가 계수 0 시작과 같은 스캔에 나고 `abs-compare` 는 다름, 누적 스캔 넘침 전후 도착 간격 판정, HSC 32비트 감김, 행정 경고 해제 3회 연속·중간 경고 시 계수 초기화, Y3A 점멸.
