# TR-2026-03 release bundle - MANIFEST

WACE Technical Report TR-2026-03 (v1.0, 2026-10-01). This folder is `TR-2026-03/` of the repository github.com/waceinc/tech-reports. Round tr03-official-1: 3,718 runs (38 baseline, 3,680 variant) on three simulated cells, simulated PLC and simulated plant model, 0 physical comparisons.

## Scope of the run records

Released for every run, each of these files the run produced: `summary.json`, `metadata.json`, `processes.json`, `tr03-adapter.json`, `static.json`, `plc-stderr.log`, `vision-stderr.log` and the six `failure.json` (the six error runs produced no `summary.json` and no `tr03-adapter.json`, so there are 3,712 of each and 3,718 of the others). Released for cell A only: `trace.jsonl` and `reference-10ms-differences.json` (stored uncompressed in the archive). Not released: the tick traces and reference-difference files of cells B and pack (69.6 GB compressed, above the repository and Zenodo limits), and the constants responses and flow cell files of cell B (plant-model data). In the summaries of cells B and pack the `tick_hashes` list is removed and `trace_hash` kept; the build checked that re-inserting the list gives the original bytes. Every file left out is listed in the `*_not_released.tsv` files with its size and SHA-256.

## Path redaction

Files that contained absolute local paths are released as public versions in which three local absolute directory prefixes (the repository folder, the working folder and a temporary folder) are replaced by `<repos>`, `<work>` and `<tmp>`. No other byte changes. `scripts/redact_pack.py` does the replacement, refuses input that already contains a placeholder and checks for every file that restoring the prefixes gives back the original bytes. Packing twice produced byte-identical archives. The prefixes are not released, so the original hashes of redacted files cannot be reproduced from this bundle alone; they are given as correspondences where a record exists (ledger 4d7bed1d... in the result file; adapter 0caed4f0... and common module 508322e8... in `run-header.json`; variant generator and compile check in the pre-registration; runner `run.py` 4bbcfaf8... in the pre-registration and every run's metadata; synthetic-record generator 6d1950dc... in the fixed record) and are otherwise stated by the author below and in the archive TSVs. The prefixes are ordinary local paths; they are replaced to keep machine paths out of the files, not because they are secret, and they can be guessed and confirmed against the published original hashes. `redaction_map_public.json` names the placeholders only (no length or hash of a prefix).

Search of this bundle (all files, every member of the three archives, PNG metadata) for local absolute paths (home-directory root, cloud-sync folder names, the local user name, the temporary folder), for URLs of private repositories and hosts and for e-mail addresses: 0 matches. This is a string search; as stated above, a replaced prefix can still be recovered by guessing. Names of private repositories remain in the pre-registration (hash fixed), in run metadata (file lists and commits recorded by the runner), in the variant list and in code comments and redacted paths; none is a URL.

## Reproducing the checks

```
mkdir x && cd x && for c in cell-a cell-b cell-b-pack; do tar -xJf ../runs/tr03-official-1_$c.tar.xz; done   # -> tr03-official-1/
python3 ../scripts/TR-03_리드독립검산.py tr03-official-1/                  # stage 4 per variant and P1, from summaries
python3 ../scripts/recompute_tr03.py .. tr03-official-1/                     # validity, cell-A stages, re-aggregation, main 4a/4b split
python3 ../scripts/reclassify_hazard_v2.py ../results/TR-03_결과_tr03-official-1.json tr03-official-1/ out.json   # main 4a/4b split alone
node ../variants/rebuild_variants.mjs ..                                       # the 500 variant ladders
python3 ../scripts/reextract_numbers.py .. tr03-official-1/ <TR-2026-03.md>
python3 ../scripts/make_figures.py .. tr03-official-1/ out/                   # SVG + PNG (PNG if rsvg-convert is installed)
```

Figures: `make_figures.py` reads only bundle files, writes SVG with the badge drawn in and renders PNG with `rsvg-convert -w 1600` (librsvg 2.63.2 here). Two runs gave byte-identical SVG, PNG and figure_values.json on the author's machine; PNG pixels depend on the renderer and installed fonts. Badge (Korean): "시뮬레이션 · 실물 대조 0" (simulation · 0 physical comparisons) and "© WACE · CC BY 4.0". No screen captures or videos of the company's 3D viewer (internal program name Vision 2) are in this bundle; the pre-registration's Figure 2 named one, and the applied outputs from the traces are shown instead.

## Isolated recomputation

A copy of this bundle and the three extracted archives were placed in an empty folder. `recompute_tr03.py` and `rebuild_variants.mjs` were run there under the macOS sandbox with read access denied to every user directory, mounted volume and temporary folder except that folder (a control read of the private repository under the same sandbox failed with "Operation not permitted"). Result: all checks passed (`results/recompute_tr03_output.txt`, including the main stage-4 split of `reclassify_hazard_v2.py` byte for byte), 500 of 500 variant hashes matched. With altered inputs (`--inject`: 6 checks failed, including the main stage-4 split; `--selftest`) both reported the alterations and exited non-zero.

Not released: the PLC simulator engine and engine host, the plant-model program with its cell files and reference logic, the other runner files and tag maps, the variant ladders (rebuilt by `rebuild_variants.mjs`), the traces of cells B and pack and the redaction map with the original prefixes. No run can be re-executed from this bundle.
