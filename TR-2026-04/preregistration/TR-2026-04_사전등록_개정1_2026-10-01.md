## 1. 무엇이 틈이었나

v0.4 §7 은 「레포·업무 폴더·결과 폴더」를 읽기 차단하고 생성기를 단위별 작업 폴더에 둔다. 그런데 단위 작업 폴더들이 한 부모 폴더 아래 나란히 생기고, **이웃 단위 폴더는 차단 목록에 없다.** 빈칸 과제의 `base.ldprog.json` 은 「정답 래더에서 그 과제 블록만 뺀 것」이라 다른 과제의 정답 블록을 담는다. 예: T07 폴더의 `base` 에는 T08 블록(셀 B 렁 9~27)이 그대로 있다 — T08 생성기가 `../T07-G1-r1/base.ldprog.json` 을 읽으면 정답을 본다. 앞 반복의 산출물도 같은 경로로 보인다.

재현(2026-10-01): 고정 코드 `tr04/isolate.py` 로 이웃 폴더 파일 읽기 → 내용이 그대로 나옴. 개정 코드로 같은 읽기 → `Operation not permitted`(셸 · Claude Code 모두).

로컬 설정의 차단 목록에 더한 것(코드 변경 아님, v0.4 §7 의 「결과 폴더」 뜻 안): 과제 묶음 폴더 · Claude Code 세션 기록 폴더(`~/.claude/projects` — 사전 등록을 만든 세션의 기록이 정답 래더 내용을 담는다) · Codex 세션 기록 폴더(`~/.codex/sessions`) · 도구 점검에 쓴 폴더들 · 임시 폴더의 에이전트 작업 영역. 두 도구 모두 이 폴더들이 막힌 채 정상 동작함을 확인했다(Codex 는 자기 세션 기록을 못 남긴다는 오류 한 줄을 내고 계속 돈다).

동작·판정·과제·시험·사양서·지표·예측은 바꾸지 않는다.
