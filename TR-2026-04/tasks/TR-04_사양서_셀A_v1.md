# 셀 A 기능 사양서 — 왕복 셔틀

정답 기준은 이 셀의 정답 래더 동작(10 ms 스캔)이다. 물리값은 실물과 대조하지 않은 가정값이다[가정].

## 1. 목적·범위

셔틀 하나가 레일 위를 오른쪽 끝과 왼쪽 끝 사이로 3 번 왕복한 뒤 멈춘다. PLC 는 기동·정지·비상정지 버튼과 양 끝 포토센서를 읽고, 정방향(오른쪽)·역방향(왼쪽) 구동 두 출력을 낸다. 공장 모형은 셔틀을 0.6 m/s 로 움직이고, 양 끝 센서는 레일 중심에서 ±0.55 m, 레일 끝은 ±0.80 m 에 있다[가정]. 끝을 넘어가면 셔틀이 떨어진다(낙하 사건).

## 2. 시간 기준

- PLC 는 10 ms 정주기로 스캔한다. 모든 시간은 스캔 수로 센다(1 스캔 = 10 ms).
- 입력은 스캔 시작에 읽고, 출력은 스캔 끝 값을 낸다. 공장 모형은 50 ms 마다 한 번 움직이며, 직전 50 ms 구간 마지막 스캔의 출력을 다음 50 ms 동안 적용한다.

## 3. 입출력

| 태그 | 주소 | 형식 | 방향 | 뜻 |
| --- | --- | --- | --- | --- |
| `A.PB.start` | `%IX0.0` | BOOL | 입력 | 기동 버튼 (누름 = 1) |
| `A.PB.stop_nc` | `%IX0.1` | BOOL | 입력 | 정지 버튼 NC (평상 = 1, 누름 = 0) |
| `A.PB.estop_nc` | `%IX0.2` | BOOL | 입력 | 비상정지 NC (평상 = 1, 누름·잠김 = 0) |
| `A.Sen.left` | `%IX0.3` | BOOL | 입력 | 왼쪽 끝 포토센서 (셔틀 있음 = 1) |
| `A.Sen.right` | `%IX0.4` | BOOL | 입력 | 오른쪽 끝 포토센서 (셔틀 있음 = 1) |
| `A.Mot.fwd` | `%QX0.0` | BOOL | 출력 | 오른쪽(정방향) 구동 |
| `A.Mot.rev` | `%QX0.1` | BOOL | 출력 | 왼쪽(역방향) 구동 |

입출력 태그의 이름·주소·형식은 바꾸지 않는다. 내부 기억의 이름·주소는 작성자가 정한다.

## 4. 매개변수

| 이름 | 값 | 뜻 |
| --- | --- | --- |
| 센서 확정 스캔 | 10 스캔(100 ms) | 양 끝 센서 원시 값이 연속으로 같아야 확정값을 바꾸는 스캔 수 |
| 방향 전환 휴지 | 25 스캔(250 ms) | 방향을 바꾸기 전 두 구동 출력을 모두 끄는 시간 |
| 왕복 횟수 | 3 | 왼쪽 끝 도착(역방향 → 정방향 전환)을 셀 때 1 씩 늘고, 3 이 되면 운전을 끝낸다 |

## 5. 동작 요구사항

- **A-01 센서 확정** — 양 끝 센서마다 따로 적용한다. 원시 값이 직전 스캔 원시 값과 다른 스캔에서 안정 계수를 0 으로 되돌리고, 계수가 10 미만이면 그 스캔에 1 을 더한다(바뀐 스캔이 1 번째). 계수가 10 이상인 스캔에서 확정값 = 원시 값, 10 미만이면 확정값은 이전 값을 유지한다. 시작 때 확정값·직전 원시 값·계수는 모두 0 이다. 이후 요구사항의 「오른쪽 도착」「왼쪽 도착」은 이 확정값을 뜻한다.
- **A-02 기동 상승** — 기동 버튼이 1 이고 직전 스캔 기동 버튼이 0 인 스캔을 「기동 상승」으로 본다. 직전 값은 스캔 끝에 저장한다.
- **A-03 비상정지 기억** — 비상정지 입력이 0 인 스캔에는 비상 기억을 켠다. 비상 기억은 「비상 확인」이 일어난 스캔에만 꺼진다.
- **A-04 비상 확인** — 비상 기억이 켜진 채 비상정지 입력이 1(해제)이고 기동 상승이 있으면 그 스캔이 「비상 확인」이다. 비상 확인은 비상 기억만 지우고 운전을 시작하지 않는다. 운전은 다음의 새 기동 상승에서 시작한다.
- **A-05 운전 조건** — 운전 기억은 다음이 모두 참일 때만 켜져 있을 수 있다: 비상정지 입력 1 · 정지 입력 1 · 비상 기억 꺼짐 · 왕복 횟수 3 미만. 이 조건이 참이고 (이미 운전 중이거나, 기동 상승이 있고 그 스캔이 비상 확인이 아니면) 운전 기억을 켠다. 조건 하나라도 거짓이면 같은 스캔에 운전 기억을 끈다. 정지·비상정지가 기동과 같은 스캔에 들어오면 정지가 이긴다. 운전이 꺼진 뒤 자동으로 다시 켜지지 않는다.
- **A-06 방향 전환 허가** — 운전 중이고 휴지 계수가 0 일 때만 방향 전환을 판단한다.
- **A-07 휴지 계수** — 운전 중이고 휴지 계수가 0 보다 크면 매 스캔 1 씩 줄인다. 운전이 꺼져 있으면 줄이지 않고 그대로 둔다.
- **A-08 역방향 전환** — 전환 허가가 있고 지금 방향이 정방향이며 오른쪽 도착이 1 이면 역방향으로 바꾸고 휴지 계수를 25 로 한다.
- **A-09 정방향 전환** — 전환 허가가 있고 지금 방향이 역방향이며 왼쪽 도착이 1 이면 정방향으로 바꾸고, 왕복 횟수를 1 늘리고, 휴지 계수를 25 로 한다.
- **A-10 처리 순서** — 한 스캔 안에서 순서는 센서 확정 → 기동 상승·비상 기억·비상 확인 → 전환 허가 판단 → 휴지 계수 감소 → 역·정방향 전환 판단 → 왕복 횟수·휴지 계수 갱신·방향 갱신 → 운전 기억 → 출력 → 기동 버튼 직전 값 저장이다. 전환 허가는 휴지 계수를 줄이기 전 값으로 판단한다. A-06·A-07 의 「운전 중」은 이 스캔에서 운전 기억을 다시 정하기 전 값(직전 스캔 끝 값)이다.
- **A-11 출력** — 정방향 구동 = 운전 기억 · 방향 정방향 · 휴지 계수 0. 역방향 구동 = 운전 기억 · 방향 역방향 · 휴지 계수 0. 두 출력이 동시에 1 이 되는 일은 없다.
- **A-12 정지 뒤 재기동** — 정지로 운전이 꺼져도 방향·휴지 계수·왕복 횟수는 그대로 둔다. 새 기동 상승으로 운전을 다시 켜면 남은 휴지부터 이어 간다.
- **A-13 3 왕복 완료** — 왕복 횟수가 3 이 되면 운전 조건이 거짓이 되어 같은 스캔에 운전을 끈다. 왕복 횟수는 PLC 를 다시 시작하기 전까지 되돌리지 않는다.

## 6. 초기 상태

첫 스캔 전 모든 내부 기억은 0 · 방향 정방향 · 휴지 계수 0 · 왕복 횟수 0 · 비상 기억 꺼짐. 두 출력 모두 0.
